# typescript-merge-project

This project implements a **merge function in TypeScript** that combines three sorted collections into one sorted array **without using the built-in sort() function**.

## Files

* `src/merge.ts` – implementation of the merge function
* `test/merge.test.ts` – unit tests using Jest

## Run Test

Install dependencies

```
npm install
```

Run unit tests

```
npm test
```

## Example

Input

```
[1,4,7]
[2,5,8]
[9,6,3]
```

Output

```
[1,2,3,4,5,6,7,8,9]
```
